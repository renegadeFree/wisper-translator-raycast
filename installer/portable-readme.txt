Wisper Translator - Windows x64
Edizione con review, ottimizzazioni e barra fluttuante in stile Raycast.

Estrarre TUTTO lo ZIP in una cartella e avviare WisperTranslator.App.exe.
Il runtime .NET e le DLL Windows x64 sono inclusi: non serve installare l'SDK.
Non avviare l'eseguibile direttamente dentro lo ZIP.

Windows 10/11 a 64 bit. La barra si apre dal pulsante Barra, dalla tray
o con Ctrl+Alt+B. Acrylic dipende dalla versione di Windows e dalle
impostazioni di trasparenza; il fondo opaco e' il fallback previsto.

I modelli e il server di traduzione vengono scaricati al primo utilizzo.
Serve Internet per questa configurazione iniziale. I dati sono salvati in
%LOCALAPPDATA%\WisperTranslator. Questo pacchetto non e' firmato digitalmente.

Sorgenti, istruzioni di compilazione e risultati CI:
https://github.com/renegadeFree/wisper-translator-raycast
docs/BUILD_WINDOWS.md e docs/CODE_REVIEW.md nei sorgenti.
Il collaudo automatico non sostituisce la prova di microfono, audio di sistema,
blur, DPI multipli e accelerazione sul proprio PC.
